# Использование ИИ

Проект подготовлен с помощью Codex, другого ИИ-агента, разрешённого условиями задания. Агент написал SQL, YAML, скрипт загрузки и сверки, Vega-Lite спеки и README. Инструкции, использованные при работе, сохранены в AGENTS.md.

Результат не принимался на доверии: SQL сверялся с отдельной реализацией расчёта на Python Decimal, запускались граничные SQL-тесты и повторная загрузка, дашборд был открыт в браузере.

Реальные ошибки и исправления в ходе работы:

1. При создании YAML агент склеил строку description и ключ dimensions. Это заметили при чтении файла, разделили строки и затем проверили загрузку YAML и наличие шести измерений и шести мер.
2. Первоначальная обработка вывода psql предполагала, что ошибки Windows всегда приходят в UTF-8. Сообщение о недоступном сервере было в другой кодировке, и декодирование скрывало исходную ошибку. Добавлен режим backslashreplace для диагностики, после чего было видно реальную причину подключения.
3. Агент сначала рассчитывал использовать Docker Desktop. Прямой запуск и CLI показали, что Docker не может запуститься в доступном окружении. Для фактической проверки использован установленный PostgreSQL 18.6. Compose для PostgreSQL 16 сохранён, но его запуск не выдаётся за проверенный.

Ошибка формулы SQL в выполненном прогоне не зафиксирована. Нет основания приписывать кандидату ручное исправление SQL, которого он не делал. Перед отправкой анкеты кандидат должен самостоятельно разобрать формулы, результаты и тесты и описать собственный вклад своими словами.
